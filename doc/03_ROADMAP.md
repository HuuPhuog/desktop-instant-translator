# ROADMAP.md

# Development Roadmap

# Phase 1 — Foundation

Goal:
Create basic desktop application structure.

Tasks:

* setup Tauri
* setup React
* setup TypeScript
* setup TailwindCSS
* configure project structure
* create base layout

Expected Result:
Application window launches successfully.

---

# Phase 2 — Selected Text Translation

Goal:
Translate selected text globally.

Tasks:

* implement global shortcuts
* implement clipboard reading
* simulate Ctrl + C
* connect translation API
* create translation popup

Hotkey:
Ctrl + Q

Expected Result:
Selected text can be translated instantly.

---

# Phase 3 — OCR Translation

Goal:
Translate text from images/screens.

Tasks:

* create fullscreen overlay
* implement drag selection
* capture screen region
* integrate Tesseract OCR
* connect OCR result to translator

Hotkey:
Ctrl + Shift + Q

Expected Result:
User can OCR any screen region.

---

# Phase 4 — UI Improvements

Goal:
Improve user experience.

Tasks:

* add dark mode
* add animations
* improve popup positioning
* improve overlay visuals
* improve responsiveness

Expected Result:
Application feels polished.

---

# Phase 5 — History System

Goal:
Save translation history.

Tasks:

* create local storage system
* create history page
* add search functionality
* add clear history option

Expected Result:
Users can revisit translations.

---

# Phase 6 — AI Features

Goal:
Enhance learning experience.

Tasks:

* grammar explanation
* vocabulary explanation
* pronunciation
* example sentences
* AI contextual explanation

Expected Result:
Application becomes AI learning assistant.

---

# Phase 7 — Production Release

Goal:
Prepare for public release.

Tasks:

* optimize performance
* fix bugs
* create installer
* create update system
* improve security
* write documentation

Expected Result:
Stable production application.
