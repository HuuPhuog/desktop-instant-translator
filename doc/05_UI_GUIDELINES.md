# UI_GUIDELINES.md

# UI Philosophy

The application UI must feel:

* minimal
* lightweight
* modern
* distraction-free
* fast

The UI should never interrupt the learning experience.

---

# Design Principles

## 1. Simplicity First

Avoid:

* large windows
* cluttered layouts
* excessive buttons
* unnecessary animations

Prefer:

* small popups
* compact controls
* clean spacing

---

# 2. Speed First

The UI must appear instantly.

Popup target:

* less than 300ms display time

---

# 3. Minimal Interaction

Users should:

* press one shortcut
* get translation immediately

Avoid multi-step workflows.

---

# Color System

## Primary Theme

Default:

* dark mode

Reason:

* comfortable during studying
* modern appearance
* less eye strain

---

# Background

Use:

* semi-transparent dark surfaces
* blur effects carefully

Avoid:

* pure black backgrounds
* overly bright colors

---

# Popup Design

## Popup Goals

The popup should:

* appear near cursor
* avoid blocking content
* disappear naturally

---

# Popup Layout

┌────────────────────┐
│ Original Text      │
│                    │
│ Translation        │
│                    │
│ Pronunciation      │
└────────────────────┘

---

# Popup Behavior

## Required

* smooth fade in
* smooth fade out
* draggable in future
* auto reposition near screen edges

---

# Overlay Design

## OCR Overlay

Requirements:

* fullscreen transparent layer
* dark transparent background
* visible selection rectangle
* smooth drag interaction

---

# Typography

Use:

* clean sans-serif fonts

Recommended:

* Inter
* SF Pro
* Segoe UI

---

# Font Sizes

Title:

* 16px–18px

Translation:

* 14px–16px

Secondary Info:

* 12px–13px

---

# Animation Guidelines

Animations should:

* feel fast
* feel subtle
* never slow down workflow

Avoid:

* long transitions
* bouncing animations
* flashy effects

---

# Spacing Rules

Use consistent spacing:

* 4px
* 8px
* 12px
* 16px

Avoid random spacing.

---

# Rounded Corners

Use:

* medium rounded corners

Recommended:

* 10px–14px radius

---

# Shadow Usage

Use soft shadows only.

Avoid:

* heavy shadows
* glowing effects

---

# Responsive Rules

UI must support:

* different screen sizes
* multiple monitor setups
* high DPI monitors

---

# Accessibility

The application should support:

* readable font sizes
* keyboard-first workflow
* good contrast ratio

---

# UX Goals

The user experience should feel:

* instant
* frictionless
* invisible
* productivity-focused

The user should remain focused on learning content, not the application itself.
